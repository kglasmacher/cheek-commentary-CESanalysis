This package is a derivative of **cancereffectsizeR** (https://github.com/Townsend-Lab-Yale/cancereffectsizeR).

This fork introduces age-dependent selection estimation (linear, logistic, and generalized sigmoid models) 
and continuous-age modeling utilities developed for the associated melanoma manuscript.  

The core methodology and implementation are by the original authors. 
This fork lightly extends those methods for age-specific modeling. 
For the canonical package and primary source of updates, please see the upstream project.
